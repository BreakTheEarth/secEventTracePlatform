# Trace v0.1.0-beta.1

面向安全工作者的日常事件运营记录平台，用于记录安全运营的工作过程数据。

本 Beta 支持具体事件记录、逐级风险研判、XLSX 批量建单、跨团队安全专项、独立待办、证据附件、事件关联、本地统计和文本上报 API。

## 下载与启动

下载本页附件 `trace-security-operations-beta-0.1.0-beta.1.zip`，解压后在项目目录执行：

```bash
npm ci
npm run build
npm start
```

需要 Node.js 22.13 或以上。浏览器访问 `http://127.0.0.1:3001`，本地体验账号 `admin` / `admin`；正式使用前修改 `.env` 中的密码。

ZIP 是完整源码包，包含 README、使用说明和演示截图，不含数据库、业务附件、真实配置、依赖或预构建文件。附带 `.zip.sha256` 可核对下载完整性。

当前为单管理员 Beta。主专项使用完整起止区间，子待办的截止日期和明细选填。负责人字段表达业务分工，不提供员工权限隔离。更多功能与部署说明见仓库首页 README。
